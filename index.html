Quick start

Use the plugin to run WordPress with SQLite instead of MySQL. The native parser extension is optional and the pure-PHP parser remains the fallback.

Run with Playground CLI

The browser links use Playground's php-extension query parameter. Locally, pass the same manifest URL to @wp-playground/cli with --php-extension before PHP starts.

npx @wp-playground/cli@latest server \
  --php=8.4 \
  --php-extension=https://wordpress.github.io/sqlite-database-integration/wp_mysql_parser-wasm-extension/latest/manifest.json \
  --blueprint=https://wordpress.github.io/sqlite-database-integration/native-extension/blueprint.json

For CI or a headless smoke test, run the Blueprint without starting a server:

npx @wp-playground/cli@latest run-blueprint \
  --php=8.4 \
  --php-extension=https://wordpress.github.io/sqlite-database-integration/wp_mysql_parser-wasm-extension/latest/manifest.json \
  --blueprint=https://wordpress.github.io/sqlite-database-integration/native-extension/blueprint.json

Replace the manifest URL with any pinned release from the table to test that exact build.
