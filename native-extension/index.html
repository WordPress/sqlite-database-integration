What it does

Native parser path

wp_mysql_parser accelerates the MySQL lexer/parser path used by SQLite Database Integration.

Pure-PHP fallback

The plugin still works without the extension; it falls back to the PHP lexer/parser when the extension is unavailable.

Playground-ready

Published manifests describe PHP 8.0–8.5 JSPI side modules that Playground can load before PHP starts.

Run with Playground CLI

Use the same manifest URL as the browser demo. The browser demo is pinned to PHP 8.3, which currently loads this extension reliably in Playground's browser runtime. The important part is --php-extension; the extension must be loaded before PHP starts.

npx @wp-playground/cli@latest server \
  --php=8.3 \
  --php-extension=https://wordpress.github.io/sqlite-database-integration/wp_mysql_parser-wasm-extension/latest/manifest.json \
  --blueprint=https://wordpress.github.io/sqlite-database-integration/native-extension/blueprint.json

Headless version:

npx @wp-playground/cli@latest run-blueprint \
  --php=8.3 \
  --php-extension=https://wordpress.github.io/sqlite-database-integration/wp_mysql_parser-wasm-extension/latest/manifest.json \
  --blueprint=https://wordpress.github.io/sqlite-database-integration/native-extension/blueprint.json
